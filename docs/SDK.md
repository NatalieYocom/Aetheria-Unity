The SDK will be upgraded to include an Automatic Avatar Converter system, that will use Watari and Poiyomi URP Shaders.
When the SDK is downloaded, Poiyomi URP and Watari will be installed. When a conversion is triggered, Watari will handle basic conversion and a second script will swap all shaders with Poiyomi URP
The SDK will contain the function to Upload to Server. The user will be given the option to select avatar visibility, profile picture, Name, Description, etc.
Login will only be needed once, and will be cached outside the editor files to keep persistent logins.
